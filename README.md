# Hermes Skills Repository

This directory contains all Hermes skills. Each subdirectory is a skill with its own SKILL.md and optional scripts, references, templates, assets.

## How to Use
- Skills are automatically loaded by Hermes from this path.
- To add a new skill, create a subdirectory under `skills/` with a valid SKILL.md.
- To update a skill, edit its files and commit changes.
- Push updates to the remote with `git push` (or set up a cron job to auto-pull/push).

## Branches
- `skills`: current working branch for skills.
