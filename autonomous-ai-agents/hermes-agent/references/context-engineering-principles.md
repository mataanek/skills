# Context Engineering Principles for Hermes Agent SOUL.md Updates

Source: arXiv:2510.26493 - "Context Engineering 2.0: The Context of Context Engineering"
https://arxiv.org/abs/2510.26493

Key concepts:
- Context engineering is the practice of designing, preparing, and managing information to shape model behavior and results.
- It treats context as a finite resource; avoid unnecessary tokens.
- Historical evolution: from early HCI frameworks to modern agent interaction paradigms and future superhuman intelligence.
- Entropy reduction view: transforming high-entropy human intentions into low-entropy, machine-understandable formats.
- Use tools, MCP servers, and skills to provide external context efficiently.
- Prefer structured note-taking and compaction for long-horizon tasks.
- Leverage subagents for parallel execution and separate context windows.
- Use CLAUDE.md for project-wide conventions, Rules for file-scoped guidance.
- Share context configurations within the team, but be aware of differing experience levels.
- Remember: context engineering increases probability of useful results but does not guarantee them; maintain human oversight.
