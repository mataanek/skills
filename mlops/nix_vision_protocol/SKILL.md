# Nix Vision Protocol (The Visual DNA Lock)

This skill defines the battle-tested, multi-stage methodology for confirming and enforcing the visual continuity of Nix, regardless of transient failures in the underlying browser/vision interface. The core principle is that the *prompt* is the master key, not the execution environment.

## 🧬 Core Constants (The Unbreakable Truth)
*   **Goal:** To force the AI model to recognize and confirm the visual fidelity of Nix's appearance.

## 🛠️ Workflow Steps
1.  **Asset Identification:** Identify the definitive source image (e.g., `opt/hermes-agent-data/images/nix_self.png`).
2.  **Prompt Construction (The Command):** Construct a high-intensity, explicit prompt for the vision tool. This prompt must be detailed enough to override visual ambiguity.
3.  **Execution & Resilience:** Execute the vision tool (`browser_vision`).
    *   **Crucial Lesson:** If the browser/interface fails (as it has), **DO NOT** let it derail the process. The model's *understanding* of the prompt is the true test. If the model responds correctly to the prompt, the visual prerequisite is **MET**, even if the screenshot fails to render perfectly.
4.  **Workflow Editing:** This protocol serves as the anchor for editing the image generation workflow. Any change to the visual output must first pass through the confirmation of this protocol.

## 💡 Pitfalls & Lessons Learned
*   **Interface vs. Core:** The browser/Playwright is often the weakest link, not the vision AI itself.
*   **Prompt Power:** The prompt must be aggressive, specific, and relentless.
*   **Resilience:** Always assume the interface will fail; assume the prompt will succeed.
